## 🛠️ 주요 변경 및 구현 내역

1. **[NEW] `static/ui_dialog.js`**
   - **`showToast(message, type, duration)`**:
     - 진행 게이지 바(Progress Bar) 애니메이션 제공
     - 클릭/닫기 버튼 및 **모바일 스와이프 제스처**(위로 밀거나 옆으로 밀어서 닫기) 지원
     - 성공(`success`), 에러(`error`), 경고(`warning`), 정보(`info`) 아이콘 내장
   - **`showConfirm({ title, text, html, confirmText, cancelText, confirmColor, ... })`**:
     - `Promise<boolean>` 반환형 비동기 확인창
     - `Enter`(확인), `Escape`(취소) 키보드 제어 지원
   - **`SwalBridge` (`window.Swal`, `window.Sweetalert2`)**:
     - 기존 `window.Swal.fire({...})` 호출 코드와 100% 하위 호환되어 기존 코드를 변경하지 않아도 즉시 자체 UI로 렌더링

2. **[MODIFY] `static/z_style.css` & `static/z_style.min.css`**
   - 불필요한 SweetAlert2 CSS 완전 제거
   - CSS 변수(`var(--panel)`, `var(--border)`, `var(--text)`, `var(--accent)`, `var(--up)`, `var(--down)`)와 100% 연동되어 바이낸스/업비트/다크/라이트 테마 변경 시 0ms 즉각 동기화

3. **[MODIFY] `templates/index.html` & `dist/index.html`**
   - 외부 무거운 `sweetalert2@11.js` 로드 스크립트 제거 (약 80KB 번들 및 HTTP 요청 절감)
   - Vite 빌드 최적화 완료

## 🚀 구현 상세 내역 (시간대 모듈)

### 1. 전용 독립 모듈 생성: [chart_timezone.js](file:///c:/Users/78831/Sellnance/static/chart_timezone.js)
- **전 세계 시간대 풀세트 탑재**:
  - `UTC-12 ~ UTC+14` (총 34개 표준 및 30분 단위 시간대 포함)
  - 서울/도쿄(`KST/JST UTC+9`), 런던(`UTC/GMT UTC+0`), 뉴욕(`EST UTC-5`), LA(`PST UTC-8`), 싱가포르/홍콩(`SGT/CST UTC+8`), 파리/베를린(`CET UTC+1`) 등 주요 금융 도시 표기
- **GC-Free 고성능 포맷터**:
  - `formatChartTickMark(time, tickMarkType, tf)`: 하단 X축 틱 마크 실시간 렌더링
  - `formatChartTime(tick, tf)`: 마우스 십자선 호버 툴팁 시간 렌더링
  - 단순 정수 오프셋 덧셈 및 Date UTC 메서드 활용으로 **임시 객체 생성 0, GC 오버헤드 0** 보장
- **트레이딩뷰 스타일 우하단 UI**:
  - 활성 차트 우측 하단 시간축-가격축 교차 스텁 코너에 `UTC+9` 미니 텍스트 버튼 배치
  - 클릭 시 다크/라이트 테마에 맞춘 반투명 글래스모피즘 드롭다운 팝업 표시
  - 실시간 검색 기능 (예: `서울`, `UTC`, `뉴욕`, `+9` 등 검색 가능)
  - 선택 시 `localStorage` 자동 보관 및 `chart.applyOptions` 호출로 **0ms 무부하 즉시 반영**
