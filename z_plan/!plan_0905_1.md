# 전 세계 시간대(UTC-12 ~ UTC+14) 변경 기능 모듈화 구현 계획

기존 캔들 데이터 및 스트리밍 구조의 변경 없이, 독립된 모듈(`static/chart_timezone.js`)을 통해 차트 우측 하단(타임스케일-가격스케일 교차 코너 스텁)에 트레이딩뷰 스타일의 시간대(Timezone) 선택 팝업 및 실시간 포맷터를 추가합니다.

---

## User Review Required

> [!IMPORTANT]
> - **데이터 무변경 (Zero Impact)**: 웹소켓, 캔들 데이터, DB 등 기존 내부 데이터(Unix 초 단위)는 일절 변경하지 않으며, 오직 **표시 라벨(포맷팅) 레이어**만 교체됩니다.
> - **기본값**: 기존 사용 환경과 100% 동일하게 **`UTC+9 (서울/도쿄, KST)`**가 기본으로 유지됩니다.
> - **저장 유지**: 사용자가 변경한 시간대 설정은 `localStorage`에 자동 저장되어 새로고침 후에도 유지됩니다.

## Proposed Changes

### 1. 신규 전용 모듈 파일 생성
#### [NEW] [chart_timezone.js](file:///c:/Users/78831/Sellnance/static/chart_timezone.js)
- **전 세계 타임존 리스트 (UTC-12 ~ UTC+14)**:
  - UTC, KST(서울), JST(도쿄), EST(뉴욕), PST(LA), GMT(런던), SGT(싱가포르), CET(파리/베를린) 등 주요 금융 중심지 및 모든 정수/30분 단위 UTC 오프셋 데이터 세트 구성.
- **포맷터 함수**:
  - `getTimezoneOffsetMinutes()`: 현재 선택된 타임존의 분(Minute) 단위 오프셋 반환
  - `formatChartTickMark(time, tickMarkType, tf)`: 하단 X축 틱 마크 렌더링
  - `formatChartTime(tick, tf)`: 마우스 십자선 호버 시간 렌더링
- **실시간 적용 및 UI 렌더링**:
  - `applyTimezoneToCharts()`: `store.chart` 및 `store.chartVol`에 `applyOptions` 즉각 반영
  - `mountTimezoneButton()`: 우측 하단 스텁 영역에 트레이딩뷰 스타일의 미니 텍스트 버튼(`UTC+9` 등) 렌더링
  - `openTimezoneMenu()` / `closeTimezoneMenu()`: 전 세계 시간대 선택 드롭다운 팝업 제어

## Verification Plan

### Manual Verification
1. **기본 동작 확인**: 초기 로드 시 `UTC+9` 버튼이 우측 하단에 깔끔하게 표시되고 X축 시간이 한국 시간(KST)으로 정확히 나오는지 확인
2. **팝업 열기/선택**: 버튼 클릭 시 다크/라이트 테마에 맞는 시간대 선택 목록이 뜨는지 확인
3. **0ms 즉각 전환**: `UTC` 또는 `UTC-5 (뉴욕)` 선택 시 차트 재로드 없이 하단 축 시간과 십자선 호버 시간이 즉각 변환되는지 확인
4. **볼륨 차트 토글 연동**: 볼륨 차트를 끄거나 켤 때도 버튼 위치 및 시간 표시가 정상 유지되는지 확인
5. **새로고침 유지**: 브라우저 새로고침 후에도 선택한 타임존이 유지되는지 확인
