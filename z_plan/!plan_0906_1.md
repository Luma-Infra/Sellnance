# 보안 잠금, 환경 정돈 및 핵심 스모크 단위 테스트(pytest/vitest) 구축 계획서

본 계획서는 외부 보안 취약점(P0 API 키 노출, 와일드카드 CORS)을 원천 차단하고, `package.json` 개발/빌드/테스트 스크립트를 표준화하며, 백엔드(`pytest`) 및 프론트엔드(`vitest`)의 핵심 10대 단위 테스트 안전망을 구축하여 프로젝트의 완성도를 상용 수준으로 끌어올리는 작업을 정의합니다.

---

## 1. 보안 잠금 (P0 결함 해결)

1. **`/api/get-env-key` 및 `/api/settings` 키 원본 노출 차단**
   - 기존: 서버의 `CMC_API_KEY` 평문 문자열을 브라우저에 반환 (`{"key": env_key}`)
   - 변경: 실제 키값은 서버 내부 메모리에서만 소비하며, API 응답은 오직 `{"has_server_key": bool}` 형태로만 반환
   - 프론트엔드(`start.js`, `settings_modal.js`)는 서버 키를 훔쳐오지 않고, 사용자 본인이 직접 브라우저에 입력한 개인 키만 `localStorage`에 격리하여 사용

2. **CORS `allow_origins` 환경변수 기반 분리**
   - 기존: `allow_origins=["*"]` + `allow_credentials=True` (공개 배포 시 취약)
   - 변경: `ALLOWED_ORIGINS` 환경변수를 파싱하되, 미지정 시 로컬 기본값(`http://localhost:8000`, `http://127.0.0.1:8000`, `http://localhost:5173` 등)으로 안전하게 제한

## 2. 개발 위생 & 스크립트 정돈 (`package.json`)

`package.json`에 표준화된 실행/빌드/테스트 스크립트 등록:
- `"dev"`: `uv run python run.py` (개발 서버 실행)
- `"build"`: CSS 빌드 + Vite 프로덕션 번들링
- `"build:css"`: Tailwind CLI minified 컴파일
- `"test"`: `pytest && vitest run` (전체 테스트 실행)
- `"test:py"`: Python 백엔드 테스트
- `"test:js"`: JS 프론트엔드 테스트

## 3. 백엔드 핵심 단위 테스트 (`pytest` 5종)

테스트 대상 파일: `tests/test_backend.py`

1. **김프(Kimchi Premium) 정산 및 USD/KRW 환율 연산 정확도 검증**
   - 글로벌 기준가 산출 공식, 환율 곱연산, 프리미엄 % 계산 무결성 검증
2. **캔들 TTL 캐시 & 요청 합승(In-flight / Semaphore) 방어 검증**
   - `candle_proxy.py`의 쿨다운 시간, 적응형 TTL 및 중복 요청 병합 동작 검증
3. **업비트 / 바이낸스 마켓 규칙 & 어댑터 데이터 정규화 검증**
   - `modules/adapter.py`, `_market_rules.js` 기준 티커, 가격, 거래소 플래그 매핑 검증
4. **UID 생성 및 중복 티커 충돌 방지 검증**
   - 업비트/바이낸스 동명 티커(예: `BTC_UPBIT`, `BTC_FUTURES`) 고유 식별자 생성 검증
5. **보안 엔드포인트 키 미노출 스모크 테스트**
   - `/api/get-env-key`, `/api/settings` 호출 시 서버 `.env` 키 평문이 절대 유출되지 않는지 검증

## 4. 프론트엔드 핵심 단위 테스트 (`vitest` 5종)

테스트 대상 파일: `tests/frontend.test.js`

1. **타임존(Timezone) UTC 오프셋 정수 연산 검증 (`chart_timezone.js`)**
   - 전 세계 34개 표준 시간대 오프셋 분(minutes) 및 초(seconds) 정밀 계산 검증
2. **티커 및 코인명 검색 가중치 정렬 검증 (`ui_search.js`)**
   - 완전 일치(Exact) > 접두사 일치(Prefix) > 포함(Includes) 순서의 정렬 무결성 검증
3. **다중 거래소 필터바 (AND / OR / ONLY) 불리언 판정 검증 (`table_filter_exch.js`)**
   - 다중 거래소 선택 및 ONLY 모드 시 코인 필터링 로직 검증
4. **시총 / 거래량 슬라이더 범위 필터링 및 세션 복원 검증 (`table_filter_custom.js`)**
   - 로그 스케일 슬라이더 수치 변환 및 `sessionStorage` 저장/복원 정합성 검증
5. **좌우 패널 스왑 토글 상태 전환 검증 (`ui_panels.js`)**
   - 스왑 호출 시 `panel-swapped`, `flex-row-reverse` 및 `localStorage` 동기화 검증
