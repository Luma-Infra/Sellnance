# /BINANCE:RAYSOL_FUTURES 새로고침 폴백 버그 & 실시간 캔들 생성 멈춤 해결

## 🛠️ 문제 원인 및 해결 내용

### 1. 새로고침 시 BTC로 강제 폴백되는 현상
- **원인:** [static/table_api.js](file:///c:/Users/78831/Sellnance/static/table_api.js)의 URL 라우트 검증(`exists`)에서 `r.Symbol`, `r.DisplayTicker`, `r.Ticker`, `r.UID`만 비교하고 있었음.
- `/BINANCE:RAYSOL_FUTURES` 진입 시 `clean`은 `RAYSOL`이나, Raydium 행의 `Symbol`은 `RAY`, `DisplayTicker`는 `RAY(Raydium)`이어서 `exists`가 `false`를 반환해 유효하지 않은 코인으로 판단하고 `BINANCE:BTC_FUTURES`로 강제 폴백됨.
- **해결:** `exists` 검증 조건에 `r.Exact_Futures === clean || r.Exact_Spot === clean || r.Exact_Futures === raw || r.Exact_Spot === raw`를 추가하여 선물 티커명(`RAYSOL`)으로 직접 접속 시에도 100% 정상 인식하도록 수정.

### 2. 점선(현재가)은 움직이나 캔들 실시간 렌더링이 멈춰있던 현상
- **원인 1:** [static/stream_utils.js](file:///c:/Users/78831/Sellnance/static/stream_utils.js)의 `isMatchingCurrentSymbol` 및 [static/stream_global.js](file:///c:/Users/78831/Sellnance/static/stream_global.js)의 `rAF` 심볼 가드에서 `store.currentSelectedSymbol`(`"BINANCE:RAYSOL_FUTURES"`)의 거래소 접두사(`BINANCE:`)와 접미사(`_FUTURES`)가 제거되지 않은 채 웹소켓 틱 심볼(`"RAYSOL"`)과 직접 비교되어 심볼 불일치로 판단하고 모든 캔들 렌더링 틱을 드랍함.
- **원인 2:** [static/stream_render.js](file:///c:/Users/78831/Sellnance/static/stream_render.js)에서 시간 역행 방지 검사 시 날짜/타임스탬프 형식 차이로 인한 비교 오차가 발생할 수 있었음.
- **해결:**
  - `isMatchingCurrentSymbol`에서 `store.currentSelectedSymbol`의 접두사(`BINANCE:`, `BYBIT:` 등)와 마켓 접미사(`_FUTURES`, `_SPOT` 등)를 완전히 제거하여 정제(`cleanTick`, `currentExpected`)하고 `Exact_Futures`, `Exact_Spot`, `DisplayTicker`, `Ticker`, `UID` 전체를 완벽 매칭하도록 개선.
  - `stream_global.js`의 중복되고 취약했던 문자열 비교를 `isMatchingCurrentSymbol` 공통 가드로 교체.
  - `stream_render.js`에서 `getUnixSeconds` 기반으로 절대 초 단위 시간 비교를 수행하여 캔들이 실시간 틱 수신 시 지연 없이 즉시 업데이트되고 새 봉이 정확하게 생성되도록 보장.
