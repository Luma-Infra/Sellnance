# 구현 계획서 - Sellnance 차트 및 UI 최적화

이 계획서는 Sellnance 트레이딩 애플리케이션의 차트 컴포넌트(Lightweight Charts), UI 버튼, 실시간 스트리밍을 최적화하여 `.chart-container` 내부의 렉(정체) 현상과 레이아웃 버그를 해결하기 위한 상세 설계입니다.

- **[MODIFY] [chart_data.js](file:///c:/Users/78831/Sellnance/static/chart_data.js)**:

- **[MODIFY] [chart_history_kimchi.js](file:///c:/Users/78831/Sellnance/static/chart_history_kimchi.js)**:

## 검증 계획

### 수동 테스트
- 로컬 개발 환경에서 애플리케이션을 구동하여 변경 사양을 확인합니다.
- 차트 하단 및 필터 버튼의 `SPOT` / `FUTURE` / `STOCK` 배지가 또렷하게 읽히는지 확인합니다.
- 타임프레임 옵션 모달에서 "2시간봉"을 껐을 때 더 이상 타임프레임 목록에 잔존하지 않고 영구 제거되는지 확인합니다.
- 12시간봉으로 바꾼 뒤 차트를 스크롤/줌 하였을 때 우측 여백이 0으로 초기화되어 캔들이 화면 오른쪽에 꽉 달라붙는 현상이 해결되었는지 점검합니다.
- 김프 차트가 표시될 때 `.chart-container` 내에서 부드럽게 연산되고 움직이는지 확인하고, 김프가 없는 코인으로 이동 시 김프 선이 안전하게 초기화되고 잔존 렉이 발생하지 않는지 체크합니다.
