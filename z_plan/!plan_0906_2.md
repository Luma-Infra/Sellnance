# 대시보드 배경색 일치 및 새로고침 시 찰나의 색상 깜빡임(FOUC) 완벽 차단 계획

사용자 피드백에 따라 다크 모드 바깥 배경색을 완전 검정(#0b0e11) 대신 **바이낸스 고유의 짙은 회색(#131722)**으로 메인 대시보드와 완벽히 일치시키고, 새로고침 시 찰나의 순간 색상이 튀는 현상을 100% 제거합니다.

---

## 1. 변경 사항 요약

### 1) [MODIFY] [templates/index.html](file:///c:/Users/78831/Sellnance/templates/index.html)
- `<head>` 최상단 즉시 실행 스크립트에서 테마 클래스(`theme-binance` / `theme-upbit`)뿐만 아니라, `document.documentElement.style.backgroundColor`를 즉시 지정하여 CSS 파일 파싱 전이라도 브라우저가 올바른 배경색(`#131722` / `#f4f5f8`)을 렌더링하도록 보장.
- `<meta name="theme-color">` 또한 다크 모드 기본에 맞게 `#131722`로 일치.

### 2) [MODIFY] [static/z_style.css](file:///c:/Users/78831/Sellnance/static/z_style.css)
- `body.theme-binance`에 하드코딩되어 있던 `background-color: #0b0e11;` (완전 검정)을 제거하여 `@layer base`의 `background-color: var(--bg)` (`#131722`)가 자연스럽게 적용되도록 통일.
- 페이지 최초 로딩 시 트랜지션 깜빡임이 생기지 않도록 `theme-transitioning` 클래스가 있을 때만 부드러운 테마 전환 애니메이션이 작동하도록 최적화.

### 3) 빌드 및 테스트
- `npm run build`를 실행하여 `dist/` 정적 파일에 Tailwind CSS 및 번들 반영.
- 단위 테스트 및 빌드 무결성 확인.

## 2. 검증 계획

### 수동 검증
1. `sellnance_skip_start`가 `true`인 상태(스킵 모드)에서 다크 모드로 페이지를 새로고침(F5 / Ctrl+R)하여 `main-dashboard-content` 바깥 영역에 어떠한 밝은 색상이나 깜빡임 없이 즉시 일체감 있는 `#131722` 배경으로 렌더링되는지 확인.
2. 라이트 모드(업비트)에서도 새로고침 시 `#f4f5f8` 배경이 매끄럽게 로드되는지 확인.
3. 상단 헤더의 테마 전환 버튼(🌙/☀️) 클릭 시에는 부드러운 0.3초 트랜지션이 여전히 잘 작동하는지 확인.
